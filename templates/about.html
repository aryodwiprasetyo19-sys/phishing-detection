ABOUT THE SYSTEM

Tentang PhishGuard XAI

Sistem deteksi website phishing berbasis web yang memadukan perbandingan empat algoritma machine learning dengan penjelasan yang dapat diinterpretasi (Explainable AI) menggunakan SHAP.

Latar Belakang & Tujuan

Serangan phishing memancing korban membuka tautan palsu untuk mencuri kredensial atau data pribadi. Deteksi otomatis membantu pengguna menilai risiko sebuah URL sebelum membukanya. Penelitian ini membandingkan kinerja empat algoritma populer, lalu menyajikan penjelasan mengapa sebuah URL diklasifikasikan sebagai phishing agar hasilnya transparan dan dapat dipercaya.

Analisis inti dilakukan dari struktur URL (lexical & structural) sehingga cepat dan tanpa mengunjungi isi situs target. Sebagai pelengkap, sistem dapat memeriksa umur domain via WHOIS secara situasional saat prediksi (dilewati bila gagal/kena limit) untuk memperkuat analisis. Hasil utama merupakan gabungan (ensemble) keempat algoritma, dan tersedia mode untuk melihat pendapat tiap algoritma.

Metodologi

  1. Ekstraksi fitur — setiap URL diubah menjadi 40 fitur numerik lexical & structural.
  2. Pra-pemrosesan — normalisasi label dan penskalaan fitur (StandardScaler), pembagian data latih/uji 80:20 secara stratified.
  3. Pelatihan & perbandingan — empat algoritma dilatih pada data yang sama dan dievaluasi memakai accuracy, precision, recall, F1-score, dan ROC-AUC.
  4. Explainability — SHAP menghitung kontribusi tiap fitur terhadap keputusan model untuk setiap prediksi.
  5. Penyajian web — hasil, tingkat risiko, penjelasan, dan saran ditampilkan melalui antarmuka web.

Explainable AI dengan SHAP

SHAP (SHapley Additive exPlanations) memberi nilai kontribusi pada setiap fitur untuk sebuah prediksi. Nilai positif mendorong keputusan ke arah phishing, sedangkan nilai negatif menariknya ke arah legitimate. Dengan begitu, pengguna tidak hanya melihat hasil akhir, tetapi juga alasan di baliknya — menjadikan model lebih transparan dan dapat dipertanggungjawabkan.

Dataset

Model dilatih menggunakan dataset publik berisi kumpulan URL phishing dan legitimate beserta labelnya. Setiap URL mentah diekstraksi menjadi 40 fitur sebelum pelatihan. Konvensi label yang dipakai: 1 = phishing, 0 = legitimate. Petunjuk penyiapan dataset tersedia di berkas README.md.
